## Root cause of checkout hang

### Immediate cause: no API key

Flow:
1. Order intent AJAX → `api.sandbox.two.inc/v1/order_intent` — **succeeds** (intent endpoint requires no API key by design)
2. Customer clicks Place Order
3. `payment.php` calls backend intent check → passes (same reason)
4. `payment.php` POSTs to `/v1/order` with no `X-API-Key` header → **401**
5. `failCheckout()` fires → `$this->errors[] = message; redirectWithNotifications('index.php?controller=order')`
6. `ps_checkout` submitted the form via AJAX — gets back a 302 redirect response
7. AJAX follows redirect, receives checkout page HTML — `ps_checkout` has no handler for this
8. UI freezes silently. Customer sees nothing.

**Fix for this customer: add their sandbox API key in the Two plugin config.**

### Structural cause: `ps_checkout` AJAX incompatibility (TWO-24768)

Our `failCheckout()` always redirects. `ps_checkout` submits payment forms via AJAX — a 302 in response to AJAX is silently swallowed. This will cause silent failures for *any* error condition on a `ps_checkout` store, not just missing API key.

We have zero `ps_checkout`-specific code in the plugin.

Tracked in Linear: [TWO-24768](https://linear.app/tillit/issue/TWO-24768)

## Secondary findings

### Multi-select rendering cosmetic bug
The "fulfilled status trigger" multi-select appears empty in the admin UI, but "Currently active: Shipped" is shown below it — the stored value is correct. Likely a type mismatch (int vs string) in our `HelperForm` option rendering causing the pre-selection to fail visually.

### Duplicate PayPal paths
`ps_checkout` bundles PayPal via its own Braintree/PayPal SDK. The standalone `paypal` module by 202 ecommerce is also enabled. Classic source of duplicate PayPal buttons and order-state collisions — worth flagging to the customer.

### `logistics_categories` v1.0.0 (Imagar)
Bespoke shipping module at initial version. Custom carrier logic hooks the cart — highest-suspicion item if shipping calculation ever misbehaves.

### `pm_advancedpack` (Advanced Pack)
Hooks cart and order creation for product bundles. If bundle products are in the cart, this can cause cart-hash drift between our intent snapshot and order creation. Monitor if reconciliation errors appear.

### `migrationpro` left installed
Heavyweight migration/upgrade tool sitting on a live (sandbox) store — disabled but should be removed.
